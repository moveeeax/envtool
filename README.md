# envtool

A small CLI for working with `.env` files.

Managing dotenv files across environments gets messy fast — keys drift between
`.env.example` and `.env`, and every service wants the values in a slightly
different shape. `envtool` aims to keep those chores honest.

Planned commands: `merge`, `diff`, `validate`, `redact`, `export`.
